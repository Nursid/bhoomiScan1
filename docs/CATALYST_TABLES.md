# Catalyst Data Store tables for BhoomiScan

Generated by `node scripts/catalyst/print-schema.js` from `src/database/catalyst/schema.js`; do not edit by hand.

Create these 14 tables in the Catalyst console (Cloud Scale → Data Store), Development environment first.
Catalyst adds `ROWID`, `CREATORID`, `CREATEDTIME` and `MODIFIEDTIME` to every table automatically; the app does not use them.

| Rule | Why |
|---|---|
| `id` is our UUID (Var Char, unique, mandatory) | URLs and API responses keep their current ids; Catalyst's own `ROWID` is not used for references |
| Columns ending in `_id` hold the related row's UUID | Catalyst foreign keys point at `ROWID`, so relations are checked by the app |
| `*_at` / dates are **BigInt** epoch milliseconds (UTC) | Catalyst DateTime has no milliseconds or time zone |
| JSON and arrays are **Text** (max 10000 characters) | Catalyst has no JSON type |
| `*_uq` columns are unique combined keys | Catalyst supports single-column unique only |
